# Bodybuilding Meal Planner

A simple, installable PWA to plan weekly meals and track macros against cutting and bulking targets.
All data lives on your device — no account, no backend, works offline.

## Features

- **Meal library** — define reusable meals with protein / carbs / fat; calories are computed
  automatically (4/4/9 kcal per gram).
- **Weekly planner** — a 7-day grid with fixed slots (Breakfast, Lunch, Dinner, Snacks). Assign
  meals from your library; add the same meal twice to double its macros (simple portioning).
- **Daily totals vs. target** — each day shows protein, carbs, fat and calories against the active
  target, with colored progress bars (under / on track / over).
- **Cutting ↔ Bulking phases** — one toggle in the header flips your targets between phases; every
  day re-evaluates instantly. Targets are fully editable.
- **Backup & restore** — export/import your data as JSON to move between devices.
- **Installable & offline** — a proper PWA (manifest + service worker).

## Default targets

Seeded on first run (all editable on the Targets tab). Personalized via the Mifflin–St Jeor
equation — BMR ≈ 1,814 × 1.55 activity = TDEE ≈ 2,812 kcal; moderate cut −500, moderate bulk +375;
protein held at ~185 g (lean-mass based), fat as a floor, carbs fill the rest:

| Phase   | Calories | Protein | Carbs | Fat |
| ------- | -------- | ------- | ----- | --- |
| Cutting | ~2,315   | 185 g   | 225 g | 75 g |
| Bulking | ~3,185   | 185 g   | 420 g | 85 g |

These are starting points — adjust from your real-world weight trend over a few weeks.

## Development

```bash
npm install
npm run dev        # dev server
npm run build      # production build to dist/
npm run preview    # preview the production build
```

The app icons in `public/` are generated by `scripts/gen-icons.mjs` (`node scripts/gen-icons.mjs`).

## Tech

React 18 + Vite, `vite-plugin-pwa` for the manifest/service worker, and `localStorage` for
persistence. State is a single object managed by a `useReducer` store in `src/state/store.jsx`;
all macro math lives in `src/lib/macros.js`.

### Deploying to GitHub Pages

The build uses a base path of `/meal-plan/` (override with the `BASE_PATH` env var). Build and
publish the `dist/` folder, e.g. `BASE_PATH=/meal-plan/ npm run build`.
